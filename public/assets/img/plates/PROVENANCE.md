# Context plates

Derived 2026-11-27 from the owner-approved originals (the imagery stage of the debox pass). Each is a small mounted print with a visible caption and credit (`Figure.astro` with `.figure--context`, `src/styles/folio/components/plate.css`), drawn at most at its file’s own width (the 320 px file at 1x, the 640 px file at 2x). They are context, not evidence: no file here is the site author’s data. Credits: the caption and the footer credit line (`src/data/colophon.ts`).

Made by `npm run images:imagery -- plates --originals <folder>` (`scripts/derive-imagery.mjs`), with every parameter in `scripts/lib/imagery-jobs.mjs`; `npm run images:verify` derives the files again and compares them with these.
