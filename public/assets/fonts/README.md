# Locally Hosted Fonts

## Current Typography

Restored the original Montserrat family for headings, body text and controls.
The existing local variable files cover weights 400-800; Latin is preloaded
and Latin Extended loads on demand. License: Montserrat-OFL.txt.
Layout stability fixes and local hosting are retained. Inter is no longer
loaded by the website; alternative-font previews remain local only.

## Previous Inter / Montserrat Pairing

Inter (variable weights 400-700) and Montserrat (variable weights 400-800).
Unmodified Latin and Latin Extended WOFF2 subsets from the Google Fonts CSS API,
retrieved 2026-09-08. The Latin files are preloaded; extensions load on demand.

Source: https://fonts.googleapis.com/css2?family=Inter:wght@400..700&family=Montserrat:wght@400..800&display=swap

Both families are distributed under the SIL Open Font License 1.1.
Original notices and licenses are included in Inter-OFL.txt and Montserrat-OFL.txt,
from https://github.com/google/fonts/tree/main/ofl .
