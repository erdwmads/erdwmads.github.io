# Locally Hosted Fonts

Inter (variable weights 400-700) and Montserrat (variable weights 400-800).
Unmodified Latin and Latin Extended WOFF2 subsets from the Google Fonts CSS API,
retrieved 2026-09-08. The Latin files are preloaded; extensions load on demand.

Source: https://fonts.googleapis.com/css2?family=Inter:wght@400..700&family=Montserrat:wght@400..800&display=swap

from https://github.com/google/fonts/tree/main/ofl .
